## English

# Independent Capstone Project: Coding Goodreads Reviews with LLMs to Study Reader Response

An independent capstone project at UW–Madison. We use large language models (LLMs) to code Goodreads book reviews on seven reader-response dimensions:

- Absence of Naive Realism
- Theme
- Thought-Provoking
- Ease
- Critic
- Surprise
- Change

The project addresses two research questions:

1. Do readers respond differently to different genres of books?
2. How much bias is introduced by treating LLM labels directly as ground truth, and how can it be corrected?

| Folder | Contents |
|---|---|
| [`Naive_LLM_analysis/`](Naive_LLM_analysis/README.md) | GPT-4o annotates 50,000 reviews; genre effects are then analyzed with OLS t-tests and a GLMM with crossed random intercepts. LLM labels are treated as ground truth here (naive annotation). |
| [`Correcting_LLM_bias/`](Correcting_LLM_bias/README.md) | Uses 100 blind human-coded labels to test the conditional independence (CI) assumption across multiple LLMs, and compares several estimators: Naive, DMM, DMM-DSL, DSL, and MLA. Conclusion: CI does not hold; DSL is recommended. |

**Reading order:** Start with `Naive_LLM_analysis` for the main analysis; its limitations motivate `Correcting_LLM_bias`. Each subfolder has its own detailed README.

**Data source:** The public UCSD Goodreads dataset. Download links are listed in `Correcting_LLM_bias/RawDataset/data_source.txt`.

**Large files not included:** The Python environment, Qwen model weights, LoRA adapter, and the one-hot CSV and annotation CSV files over 50 MB in `Naive_LLM_analysis`. See `.gitignore` for details.

- The annotation results are kept in `Naive_LLM_analysis/data/annotated/annotated_50000sample.xlsx`.
- The one-hot CSVs can be regenerated by running the `.qmd` files in `code/03_OLS_ttest` and `code/04_GLMM`.

## 中文版

# Independent Capstone Project：用 LLM 编码 Goodreads 书评，研究读者反应

UW–Madison 独立毕业设计（capstone）项目。我们用大语言模型（LLM）给 Goodreads 书评编码，共 7 个读者反应维度：

- Absence of Naive Realism
- Theme
- Thought-Provoking
- Ease
- Critic
- Surprise
- Change

研究问题有两个：

1. 不同类型的书，读者的反应是否不同？
2. 把 LLM 标签直接当真值用会产生多大偏差，又该如何纠正？

| 文件夹 | 内容 |
|---|---|
| [`Naive_LLM_analysis/`](Naive_LLM_analysis/README.md) | GPT-4o 标注 50,000 条书评，然后用 OLS t 检验和 GLMM（交叉随机截距）分析 genre 效应。这里把 LLM 标签当真值使用，即 naive annotation |
| [`Correcting_LLM_bias/`](Correcting_LLM_bias/README.md) | 用 100 条盲编人工标签检验多个 LLM 的条件独立（CI）假设，并比较 Naive、DMM、DMM-DSL、DSL、MLA 几种估计方法。结论：CI 不成立，推荐 DSL |

**阅读顺序：** 先读 `Naive_LLM_analysis`，了解主分析；它的局限引出 `Correcting_LLM_bias`。两个子文件夹各有详细的 README。

**数据来源：** UCSD Goodreads 公开数据集，下载地址见 `Correcting_LLM_bias/RawDataset/data_source.txt`。

**没有上传的大文件：** Python 环境、Qwen 模型权重、LoRA adapter，以及 `Naive_LLM_analysis` 里超过 50 MB 的 one-hot CSV 和标注 CSV，具体见 `.gitignore`。

- 标注结果保留在 `Naive_LLM_analysis/data/annotated/annotated_50000sample.xlsx`。
- one-hot CSV 可以运行 `code/03_OLS_ttest` 和 `code/04_GLMM` 里的 qmd 重新生成。
